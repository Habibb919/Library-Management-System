Library Management System

A Python-based Library Management System that helps manage books and users.

Features

* Add new books
* View all books
* Search books
* Register users
* Borrow books
* Return books
* View borrowed books
* Save and load data using JSON

Project Structure

* main.py — Main program and menu
* book.py — Book class
* user.py — User class
* library.py — Library management functions
* data.json — Data storage

Concepts Used

* Object-Oriented Programming (OOP)
* Classes and Objects
* Functions and Methods
* Lists and Dictionaries
* JSON
* File Handling
* Exception Handling

How to Run

python main.py
